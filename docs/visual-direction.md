# اتجاه التصميم

الهدف: موقع إيوان يشرح قيمة البرمجيات من خلال مشاريع فعلية، بتكوين مركزي وألوان وخلفيات النسخة الأصلية الداكنة. يظل الشعار المعماري هو العنصر البصري الأساسي.

## الألوان والخطوط

| الدور | اللون |
| --- | --- |
| الخلفية | `#060E11` |
| سطح رئيسي | `#0C1B1D` |
| سطح مرتفع | `#19362F` |
| حواف وانعكاسات | `#59B39D` |
| لون تفاعلي | `#A3DECE` |
| النص الرئيسي | `#EFF7F5` |

Thmanyah Sans للنص العربي وThmanyah Serif Display للعناوين، من المصدر الذي حدده صاحب المشروع. Inter للنص الإنجليزي وDM Serif Display للعناوين؛ الأخير بديل للعناوين إلى حين توافر ترخيص TAN Headline. الخطوط تعمل محليًا، وتفاصيل المصادر في `reference-study.md`. العناوين الثانوية أصغر من الهيرو، والفقرات ذات طول سطر محدود.

## التكوين

```text
           [ الشعار + إيوان للبرمجيات 3D ]
          [ برمجيات بإتقان. أعمال بانسياب. ]
                 [ شريط الشراكات ]
      [ معاينة تعلّم بوعي ] [ معاينة الفلاح ]
        [ وصف وخصائص ]     [ وصف وخصائص ]
             [ شريط الخدمات / صفّان ]
              [ عرض فوائد النظام ]
                [ مراحل التنفيذ ]
                [ أبرز العملاء ]
              [ عن إيوان / الفيديوهات ]
           [ عنوان التواصل / نموذج مركزي ]
```

شبكة الأعمال تعرض مشروعين متساويين في الصف على الشاشات الأكبر من 820 بكسل، وعمودًا واحدًا تحت هذا العرض. لكل مشروع معاينة ثم وصف مفصل وخصائص أساسية ورابط الزيارة. تتسع الشبكة تلقائيًا للمشاريع التالية دون تغيير القالب. الشريط المتحرك يظل منخفض الارتفاع، وحركة الشعار تتبع الماوس، والعرض السينمائي يحافظ على أبعاده عند تغيير المشاهد.

طلب صاحب المشروع إعادة الألوان والتدرجات السابقة؛ لذلك أُزيلت تغييرات الخلفيات والألوان والظلال من ملف `visual-polish.css`، وبقي دوره تنظيم التكوين والخطوط والمسافات. تعتمد الألوان على الملفات السابقة للـ checkpoint. جرى التحقق من مطابقة الألوان والتدرجات في 19 عنصرًا من الصفحة.

أُضيف الوضع الفاتح لاحقًا كخيار مستقل في `themes.css`؛ تظل ألوان الوضع الداكن السابقة كما هي. يستخدم الفاتح خلفية `#F5F8F4` ونصًا أساسيًا `#193D30` ونصًا ثانويًا `#4D685A` ولون تفاعل `#195F47`. له صورة معمار نهارية مخصّصة وشعار أخضر واضح. الاسم في الهيرو نص حي ثلاثي الأبعاد باللغتين، والسلوجان سطر واحد أصغر. الانتقال بين الوضعين كشف دائري ينطلق من زر الوضع، وتفاصيل الأصل البصري محفوظة في `light-mode.md`.

وصف الفلاح يبرز منظومة إدارة المدرسة والمتابعة وأتمتة المستندات، حسب شرح صاحب المشروع والمعاينة السابقة للقراءة فقط. وصف تعلّم بوعي يستند إلى [الصفحة الرئيسية](https://taalambwaey.com/) وصفحة الدورة العامة: المحاضرات والشهادات، والتسجيل والشراء، وانضمام المحاضرين، واللغتان وعرض الأسعار بعملات متعددة. لم نضف أرقام نتائج أو ادعاءات أداء غير موثّقة.

تجنّبنا إضافة حركة دخول لكل قسم أو أشعة تتحرك مع التمرير. الصور تعرض المشاريع الفعلية، والخصائص تصف ما قدّمه صاحب المشروع. الآراء المكتوبة مسودات واضحة، والفيديوهات القادمة مواضع انتظار معلّمة.

## نقاط الرجوع

- `main`: النسخة المرفوعة قبل التعديلات الجمالية.
- `checkpoint-before-visual-polish`: علامة ثابتة لنقطة الرجوع.
- `checkpoint-before-light-mode`: نسخة شبكة المشاريع قبل إضافة الوضع الفاتح والهيرو باسم الشركة.
- `checkpoint-before-reference-details`: نسخة الوضعين قبل تحديث الخطوط والشريط والنيون والتكتشر.
- `design/visual-polish`: شبكة المشاريع والنصوص والمسافات والتواصل والوضعان الداكن والفاتح.
