# اتجاه التصميم

الهدف: موقع إيوان يشرح قيمة البرمجيات من خلال مشاريع فعلية، بتكوين مركزي وخلفيات زمردية أوضح. يظل الشعار المعماري هو العنصر البصري الأساسي.

## الألوان والخطوط

| الدور | اللون |
| --- | --- |
| الخلفية | `#09191C` |
| سطح رئيسي | `#102927` |
| سطح مرتفع | `#1E4436` |
| حواف وانعكاسات | `#74B79D` |
| لون تفاعلي | `#A3DECE` |
| النص الرئيسي | `#EFF7F5` |

IBM Plex Sans Arabic للعربية وGeist للإنجليزية، بخطوط محلية مرخّصة. العناوين الثانوية أخف وأصغر من الهيرو، والفقرات ذات طول سطر محدود.

## التكوين

```text
              [ الشعار + عنوان الهيرو ]
                 [ شريط الشراكات ]
   [ معاينة الفلاح الكبيرة ] [ وصف وخصائص ]
   [ وصف وخصائص ] [ معاينة تعلّم بوعي الكبيرة ]
              [ عرض فوائد النظام ]
                [ مراحل التنفيذ ]
                  [ شركائنا ]
              [ عن إيوان / الفيديوهات ]
           [ عنوان التواصل / نموذج مركزي ]
```

على الموبايل تُعرض صورة كل مشروع قبل وصفه في عمود واحد. الشريط المتحرك يظل منخفض الارتفاع. التظليل ثابت وموضعي، ولمعة الحواف محدودة للمعاينات والفريم والنموذج. حركة الشعار تتبع الماوس، والعرض السينمائي يحافظ على أبعاده عند تغيير المشاهد.

تجنّبنا إضافة حركة دخول لكل قسم أو أشعة تتحرك مع التمرير. الصور تعرض المشاريع الفعلية، والخصائص تصف ما قدّمه صاحب المشروع. الآراء المكتوبة مسودات واضحة، والفيديوهات القادمة مواضع انتظار معلّمة.

## نقاط الرجوع

- `main`: النسخة المرفوعة قبل التعديلات الجمالية.
- `checkpoint-before-visual-polish`: علامة ثابتة لنقطة الرجوع.
- `design/visual-polish`: تحسينات الخلفيات وعرض المشاريع والنصوص والمسافات والتواصل.
