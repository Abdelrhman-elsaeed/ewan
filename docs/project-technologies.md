# تقنيات المشاريع المعروضة

أُضيفت الأيقونات والأسماء إلى بطاقات الأعمال بناءً على ملفات إعداد المشروعين التي أذن صاحب المشروع بمراجعتها. اقتصر الفحص على المستودعات وملفات التعريف، دون تشغيل التطبيقات أو تعديل أنظمة العملاء.

## الفلاح

| المعروض | الدليل |
| --- | --- |
| Angular | حزم Angular 17 في `frontend/package.json` |
| TypeScript | TypeScript 5.4 ضمن إعداد بناء الواجهة |
| C# / .NET | مشروع ASP.NET Core يستهدف .NET 8 |
| EF Core | حزم Entity Framework Core في طبقة Infrastructure |
| SQL Server | موفّر `Microsoft.EntityFrameworkCore.SqlServer` |
| SignalR | اعتماد `@microsoft/signalr` في الواجهة |

## تعلّم بوعي

| المعروض | الدليل |
| --- | --- |
| Laravel | `laravel/framework` 11 في `composer.json` |
| PHP | متطلب PHP 8.2 في Composer |
| Blade | قوالب Blade في المشروع، وتوزيع اللغات الذي قدّمه صاحب المشروع |
| Alpine.js | `alpinejs` في `package.json` |
| Tailwind CSS | `tailwindcss` وملحق النماذج في إعداد الواجهة |
| Vite | أمر البناء واعتماد Vite 6 |

لا تُعرض إصدارات الحزم في واجهة الوكالة. لم نُدرج قاعدة بيانات أو مزوّد دفع لتعلّم بوعي دون دليل إعداد كافٍ ضمن نطاق هذا الفحص.

## التصميم والأصول

كل بطاقة تعرض ست تقنيات بأيقونات داخل مربعات صغيرة، وأسماء إنجليزية واضحة. تلتف العناصر على الشاشات الصغيرة، ويتكيّف السطح والنص مع الوضعين. الأيقونات الخارجية من Devicon v2.17.0، وترخيصها مرفق في `site/assets/tech/LICENSE-devicon.txt`. EF Core وSignalR وBlade تستخدم رموزًا هندسية دلالية مكتوبة في SVG ضمن الصفحة.

عُدّل لون أيقونتَي Angular وPHP أحاديتَي اللون إلى وردي فاتح وبنفسجي فاتح لظهورهما بوضوح على الخلفية الداكنة، مع بقاء شكلهما الأصلي.

تنسيقات الصف في `site/assets/project-stacks.css`، والعناوين تُترجم بواسطة `techLabel` داخل `content.js`. مصادر المشاريع الخاصة بقيت خارج مستودع موقع الوكالة؛ لا تُنسخ إعداداتها أو مفاتيحها إلى ملفات التسليم.
